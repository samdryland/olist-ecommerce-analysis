# olist-ecommerce-analysis
SQL and Power BI analysis of the Olist Brazilian e-commerce dataset, focusing on sales performance, customer satisfaction and repeat purchasing.


# Olist E-commerce Analysis

## Objective

Analyse the Olist Brazilian e-commerce dataset to understand sales
performance, customer satisfaction and repeat purchasing behaviour.

## Tools

- SQL
- SQLite
- DB Browser for SQLite
- Power BI

## Key Questions

- What products drive sales?
- How does demand vary geographically and seasonally?
- Which products have high sales but poor customer satisfaction?
- How many customers return?
- What factors are associated with repeat purchasing?

## Project Status

Currently exploring and assessing the data quality.
